# Phasefield 4OP

A four-operator spatial FM synthesizer. Each operator is a periodic oscillator over a two-dimensional coordinate; eight routing algorithms determine which operators modulate other operators' phase and which are mixed as carriers. Ten operator waveforms include sine, triangle, sawtooth, square, and pulse.

[Try Phasefield 4OP on GitHub Pages](https://ixxyxr.github.io/phasefield-texture-lab/)

There is no authentication, database, persistence, analytics, external API, noise generator, or spatial-warp stage.

## Run

```text
npm install
npm run dev
```
